# How I created an e-portfolio

### Introduction:

These are the steps I took to create an E-portfolio on GitHub. An e-portfolio allows you to display your best work. The e-portfolio on my site is a resumé format, but it can serve any purpose. For my current projects, I have been using Python in VS Code to create data visualizations like graphs and charts. Here is an image of something I recently did: 

<img src="../assets/img/examplecode.png" alt="Alt text description" width="500">

Follow the steps below and you can create your own site too!\
*__Note:__* These instructions are for GitHub website, not desktop app. 

## *Step 1:*

<img src="../assets/img/step1.png" alt="Alt text description" width="500">

Create a GitHub account. I already had one (NatCSMCC).

## *Step 2:*

<img src="../assets/img/step2.png" alt="Alt text description" width="500">

Pick a theme through GitHub's pages. I am using the "Minimal," a Jekyll theme. There are many more themes, but Minimal is a simple one. This is the  to the theme and its source code:
Download the ZIP file then unzip and extract its contents.

[This is the link to view GitHub's Minimal theme](https://github.com/pages-themes/minimal)

[This is the link to view GitHub's various themes](https://github.com/pages-themes)

## *Step 3:*

<img src="../assets/img/step3b.png" alt="Alt text description" width="500">

Clone the repository from GitHub onto your computer with a new file OR find the local copy of your repository. Mine is "NatCSMCC.github.io". 

## *Step 4:*

<img src="../assets/img/step4a.png" alt="Alt text description" width="500">

On your GitHub repository, look at the README.md file. It has instructions from the Minimal theme to  help you change your website. Next, open the configuration file (_config.yml). Here, you can change information like the title, description, or even adding a photo to your site. Hit the edit button to change the code and the preview button will show how the markdown appears on the site. 

Below is an image of my current README.md file. When you clone your repository, your README.md will be the same as Minimal's. I changed mine later to show my portfolio information instead of the default minimal theme instructions.

<img src="../assets/img/step4b.png" alt="Alt text description" width="500">

## *Step 5:*

<img src="../assets/img/step5a.png" alt="Alt text description" width="500">

Add a headshot photo to your site by renaming the photo to something like "logo.png" on your computer then replace the photo in the "assets" file. You can also add more images in this file for elsewhere on the site. Replace the code in the config file to make sure the path and name of image is correct. Like this:

logo: /assets/img/logo.JPG

<img src="../assets/img/step5b.png" alt="Alt text description" width="500">

<img src="../assets/img/step5c.png" alt="Alt text description" width="500">

<img src="../assets/img/step5d.png" alt="Alt text description" width="500">

## *Step 6:*

<img src="../assets/img/step6.png" alt="Alt text description" width="500">

To change the contents on your site, open the index.md file. You can replace the existing template. Since mine was resumé format, I included my personal description, work and education history, and some personal/professional goals.

## *Step 7:*

<img src="../assets/img/step7a.png" alt="Alt text description" width="500">

You can use markdown features to change text to bold, italics, make ordered lists, create headers, include links, etc. 

<img src="../assets/img/step7b.png" alt="Alt text description" width="500">

[This is the link for the Markdown list on GitHub](https://docs.github.com/en/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/basic-writing-and-formatting-syntax)

## *Step 8:* 

Save and publish by selecting the "Commit changes" button. Check if your website was successful by opening a new tab and typing your username.github.io

<img src="../assets/img/step8a.png" alt="Alt text description" width="500">

Success!

<img src="../assets/img/step8b.png" alt="Alt text description" width="500">



### *Tips:*
1. Refer back to the minimal theme instructions if stuck.
2. Commit changes regularly to save files manually.
3. Check if actions were successful in the actions tab.  


# Creating a subpage (optional)

## Introduction:

These are the steps I took to create a subpage on my site. A subpage is a nested site within your site. Someone viewing your GitHub site will be able to click the link and go to your subpage. You are looking at my subpage right now!

## *Step 1:*

<img src="../assets/img/op1a.png" alt="Alt text description" width="500">

Create a folder and give it a descriptive name (probably not "subpage_1"). Mine is "Portfolio_Steps". For this example, I named it "exampleFile". Add a forward slash / after that name. It will create a file. Name that one index.md. 

<img src="../assets/img/op1b.png" alt="Alt text description" width="500">

## *Step 2:*

<img src="../assets/img/op2.png" alt="Alt text description" width="500">

Now, in markdown, you can edit the file to include whatever you want. In this case, it is a step-by-step guide. You can include links and images in your subpage as well. Commit changes to save and publish. 

## *Step 3:*

<img src="../assets/img/op3.png" alt="Alt text description" width="500">

Add a link to the subpage on your main site. To do this, open the index.md file in the root folder and create a new section/header in your markdown to indicate what it is and add the link. It should look like a normal link format, but the link will be the name of the subfolder. For me, it is /Portfolio_Steps/ 

Then commit changes again.

## *Step 4:*

<img src="../assets/img/op4.png" alt="Alt text description" width="500">

Check that everything works! Check your actions tab to see if they were successful. Then, visit your GitHub site and check to see if the changes took place. Locate the subpage then click on it and make sure it has all the info you included.
